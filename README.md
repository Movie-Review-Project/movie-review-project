
# 🎬 시네로그 (CineLog)

### 영화 리뷰 및 개인 관람 기록 관리 시스템

Python 기반 콘솔 프로그램으로 영화 정보를 검색하고, 리뷰와 평점 및 개인 관람 기록을 관리하는 프로젝트입니다.

---

## 📖 프로젝트 소개

다양한 극장·OTT 플랫폼에서 관람한 영화의 기록을 한곳에 모아 관리할 수 있도록 기획했습니다.

사용자는 영화 정보를 검색하고, 관람한 작품의 리뷰와 평점을 남기거나 다른 사용자의 평가를 확인할 수 있습니다.

## ✨ 주요 기능

| 구분 | 기능 |
|---|---|
| 👤 **회원 관리** | 회원가입, 로그인, 회원 정보 조회 및 관리 |
| 🎥 **영화 정보 조회** | TMDB API를 활용한 제목·줄거리·장르·개봉일 조회 |
| 🔍 **영화 검색 및 정렬** | 제목·장르별 검색, 평점순·개봉일순 정렬 |
| ⭐ **리뷰 및 평점 관리** | 리뷰 작성·조회·수정·삭제, 다른 사용자의 리뷰 조회 |
| 📊 **리뷰 검색 및 정렬** | 영화별 리뷰 조회, 평점 및 추천/비추천 기준 정렬 |
| 📅 **관람 기록** | 개인이 관람한 영화와 리뷰 조회 |
| 💾 **데이터 저장** | JSON 파일을 활용한 회원·영화·리뷰 데이터 저장 및 불러오기 |

> **참고:** 위 내용은 기획 단계에서 정의한 주요 기능이며, 개별 기능의 구현 완료 여부를 의미하지 않습니다.

## 📁 프로젝트 구조

```text
project/
│
├── main.py                     # 프로그램 실행 및 메뉴 관리
│
├── models/                     # 데이터 모델 정의
│   ├── member.py               # Member 클래스
│   ├── movie.py                # Movie 클래스
│   └── review.py               # Review 클래스
│
├── managers/                   # 데이터 및 기능 관리
│   ├── member_manager.py       # 회원가입, 로그인, 회원 관리
│   ├── movie_manager.py        # 영화 검색, 영화 관리
│   └── review_manager.py       # 리뷰 작성, 수정, 삭제
│
├── data/                       # JSON 데이터 파일
│   ├── members.json            # 회원 데이터
│   ├── movies.json             # 영화 데이터
│   └── reviews.json            # 리뷰 데이터
│
└── .gitignore                  # Git 추적 제외 설정
```

## 📂 디렉터리별 역할

| 디렉터리 | 역할 |
|---|---|
| `main.py` | 프로그램 실행 및 사용자 메뉴 관리 |
| `models/` | Member, Movie, Review 클래스 정의 |
| `managers/` | 회원, 영화, 리뷰 관련 비즈니스 로직 처리 |
| `data/` | JSON 파일을 통한 데이터 저장 및 불러오기 |

### Models
각 데이터 객체의 속성과 데이터 변환 메서드를 정의합니다.

- `Member`: 회원 정보
- `Movie`: 영화 정보
- `Review`: 리뷰 및 평점 정보

### Managers
데이터 조회, 등록, 수정, 삭제 등의 기능을 담당합니다.

- `MemberManager`: 회원가입, 로그인, 회원정보 관리
- `MovieManager`: 영화 검색 및 영화정보 관리
- `ReviewManager`: 리뷰 작성, 조회, 수정, 삭제 및 정렬

### Data
프로그램에서 사용하는 데이터를 JSON 형식으로 저장합니다.

- `members.json`: 회원정보
- `movies.json`: 영화정보
- `reviews.json`: 리뷰정보


## 🚀 실행 방법

### 1. 저장소 클론

```bash
git clone https://github.com/Movie-Review-Project/movie-review-project.git
cd movie-review-project
```

### 2. Python 설치 확인

```bash
python --version
```

### 3. 실행 환경 설정

프로젝트 실행에 필요한 외부 라이브러리를 설치하고 TMDB API 인증 정보를 설정합니다.

> 구체적인 라이브러리 및 API 설정 방법은 추후 업데이트 예정입니다.

### 4. 프로그램 실행

```bash
python main.py
```

운영체제에 따라 다음 명령어를 사용해야 할 수 있습니다.

```bash
python3 main.py
```

## 🤝 협업 방식

GitHub를 활용하여 기능별 브랜치에서 개발하고, Pull Request를 통해 변경사항을 관리합니다.

1. 기능별 브랜치를 생성하여 작업합니다.
2. 개발한 기능을 Commit 및 Push합니다.
3. Pull Request를 생성하여 `main` 브랜치에 병합을 요청합니다.
4. 코드 검토 후 `main` 브랜치에 Merge합니다.
5. 최신 `main` 브랜치의 변경사항을 반영하고 개발을 이어갑니다.

> 공통으로 사용하는 Model 및 Manager의 인터페이스가 변경되면 팀원들과 공유합니다.
